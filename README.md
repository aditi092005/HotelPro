# 🏨 HotelPro — Hotel Management System

**HotelPro** is a web-based hotel management application developed to provide a convenient and user-friendly platform for hotel-related operations. The project follows a client-server architecture, with separate frontend and backend components.

## 📌 About the Project

HotelPro aims to simplify hotel management through a web-based interface. The project is organized into frontend and backend modules to support a structured and maintainable application.

## 🎯 Objectives

- Develop a user-friendly hotel management application.
- Organize the application using a client-server architecture.
- Provide an interactive frontend interface.
- Implement backend functionality for handling application requests.
- Support database integration according to the project configuration.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/aditi092005/HotelPro.git
```

### 2. Open the Project Directory

```bash
cd HotelPro
```

### 3. Install Backend Dependencies

```bash
cd server
npm install
```

Configure the environment variables required by the backend. Start the server using the appropriate command defined in `server/package.json`.

### 4. Install Frontend Dependencies

Open a new terminal and navigate to the client directory:

```bash
cd "D:\hotel management\HotelPro\client"
npm install
```

Start the frontend using the development command defined in `client/package.json`.

### 5. Run the Application

Once the frontend and backend are running, open the local URL displayed in the frontend terminal.

**Note:** The exact startup commands and environment variables depend on the project's configuration.
